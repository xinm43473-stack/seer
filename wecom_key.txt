# 企业微信群机器人 Webhook Key
#
# 改 key 只需要改这个文件，不用动 seer_run.ps1。
#
# 两种写法都可以（下面第二行就是当前生效的值）：
#   YOUR-KEY-HERE
#   key=YOUR-KEY-HERE
#   也可以直接粘整条地址：
#   https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR-KEY-HERE
#
# 规则：
#   - 只读"第一条非空、非 # 开头的行"，所以下面的示例不会被读取
#   - 以 # 开头的行是注释，会被忽略
#   - 文件删掉也没关系，会回退到脚本里内置的 key
#   - 命令行 -Webhook "..." 优先级最高
#
# 怎么拿到 key：企业微信群 -> 右上角 -> 群机器人 -> 添加机器人 ->
#               新创建一个 -> 复制它的 Webhook 地址，其中的 key= 后面那串就是
YOUR-KEY-HERE
